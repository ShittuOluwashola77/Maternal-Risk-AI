# 🤱 MaternalAI

MaternalAI is an AI-powered maternal health decision support system that combines Machine Learning and Large Language Models to provide maternal risk prediction and educational explanations.

---

## Features

- Maternal Risk Prediction
- AI Clinical Explanation
- Prediction History
- Prediction Analytics Dashboard
- Prediction Logging
- Professional UI
- Error Handling
- Clinical Input Validation

---

## Technology Stack

- Python
- Streamlit
- Scikit-learn
- Gradient Boosting
- Groq API
- Pandas
- NumPy

---

## Run

```bash
pip install -r requirements.txt

streamlit run app.py
```
